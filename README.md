# React Landing (Vite)

A clean, modern React landing page template (no Tailwind). Uses:
- React 18 + Vite 5
- React Router (scaffolded)
- Framer Motion for subtle animations
- Plain CSS per component (imported via `App.css`)

## Quickstart
```bash
# 1) unzip
unzip culture-lens.zip
cd culture-lens

# 2) install
npm i

# 3) run dev
npm run dev
# Vite will print a localhost URL; open it in your browser
```

## Build for production
```bash
npm run build
npm run preview
```

## Customize
- Edit colors in `src/App.css` under `:root` variables.
- Update copy & links in `src/components/*`.
- Replace gallery image URLs with your own.
